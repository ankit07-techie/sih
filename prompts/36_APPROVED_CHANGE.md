# Prompt 36 — Implement Approved Change

Implement only the approved scope.

Before editing, ensure unrelated uncommitted work is not overwritten.

After:
- run relevant tests
- add regression tests when needed
- inspect diff and diff stat
- update docs when required
- create one logical Conventional Commit
- push without force
- verify clean status

Report summary, files, tests, commit hash/message, push result, and rollback reference.
Stop.
