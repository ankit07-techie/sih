# PassiveShield AI

AI-assisted cybersecurity threat detection for strictly passive, unidirectional IP traffic.

## Development philosophy
Small task → inspect → plan → implement → test → inspect diff → commit → push → stop.

The repository is intentionally designed for:
- isolated changes
- stable contracts
- easy debugging
- deterministic replay
- small logical commits
- safe rollback

Read `PROJECT_CONSTITUTION.md` before making changes.
