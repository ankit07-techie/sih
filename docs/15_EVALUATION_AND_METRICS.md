# Evaluation and Metrics

## Detection evaluation
Use precision, recall, F1, and confusion matrices when labeled data supports them.
For anomaly detection, document representative true positives and false positives.

## System metrics
Measure:
- processing rate
- sustained throughput
- alert latency
- errors
- memory where practical

## Measurement record
Record:
- hardware/environment
- input dataset/replay
- duration
- configuration
- command
- measured result

Targets and measured results must never be presented as the same thing.
