# Development Protocol

Every Antigravity task follows:

1. inspect current Git state
2. read relevant docs
3. inspect relevant code and recent commits
4. define exact scope
5. list likely files
6. identify contract impact
7. implement the smallest safe change
8. test
9. debug if needed
10. inspect diff and diff stat
11. update docs if behavior/design changed
12. create one logical commit
13. push without force
14. verify clean status
15. report and stop

Agents must not continue automatically into the next milestone.
