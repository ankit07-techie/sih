# Standardized ThreatAlert Data Contract Specification

## Executive Summary
This document specifies the schema, field validation rules, serialization formats, threat classifications, severity levels, and test verification results for the standardized `ThreatAlert` data contract ([`shared/contracts/threat_alert.py`](file:///d:/sih%20project/PassiveShield_AI_v2/shared/contracts/threat_alert.py)).

---

## 1. Contract Overview & Fields

The `ThreatAlert` contract represents a correlated, standardized security alert generated by PassiveShield AI analytics engine and emitted to downstream alert buses (Redpanda `threat-alerts` topic, Redis Pub/Sub, Node.js Express API, and WebSockets for the SOC dashboard).

- **Location**: `shared/contracts/threat_alert.py`
- **Schema Version**: `1.0`
- **Event Type Identifier**: `ThreatAlert`

### Field Definitions

| Field Name | Type | Description | Validation Constraints |
|---|---|---|---|
| `alert_id` | `str` | Unique UUID v4 identifying the threat alert instance | Non-empty string |
| `timestamp` | `str` | ISO 8601 UTC timestamp of alert generation | Non-empty ISO 8601 string |
| `threat_classification` | `str` | Standardized category of security threat | Must be valid classification |
| `severity` | `str` | Standardized alert severity level | Must be `INFO`, `LOW`, `MEDIUM`, `HIGH`, or `CRITICAL` |
| `confidence_score` | `float` | Aggregated threat confidence score | Must be between `0.0` and `1.0` inclusive |
| `affected_context` | `Dict[str, Any]` | Target entity context (entity_type, entity_id, IPs, subnets) | Non-null dictionary |
| `observation_window_seconds` | `int` | Sliding observation window duration | Must be $> 0$ |
| `contributing_detectors` | `List[str]` | List of detector names that contributed to this alert | Non-null list |
| `structured_evidence` | `List[Dict[str, Any]]` | Preserved array of `ThreatEvidence` objects | Array of evidence dicts |
| `mitigation_recommendation` | `str` | Recommended SOC action | Non-empty string |
| `event_type` | `str` | Event type tag (`"ThreatAlert"`) | Default `"ThreatAlert"` |
| `version` | `str` | Contract version (`"1.0"`) | Default `"1.0"` |

## 2. Standardized Classifications & Severities

### Approved Threat Classifications
- `DDOS_ATTACK`: Volumetric HTTP/SYN floods or traffic surges.
- `PORT_SCAN`: Vertical port scanning, horizontal IP sweeps, or stealth probes.
- `C2_BEACONING`: Periodic Command and Control inter-arrival patterns.
- `DNS_ANOMALY`: Algorithmic DGA queries or DNS TXT tunneling exfiltration.
- `DATA_EXFILTRATION`: High-volume directional outbound byte transfers or robust Z-score spikes.
- `TLS_ANOMALY`: Malicious JA3/JA4 fingerprint matches, weak ciphers, or missing SNI.
- `CORRELATED_MULTI_VECTOR`: Multiple distinct detector vectors triggering on the same entity.
